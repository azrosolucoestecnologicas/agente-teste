# Meu assistente de IA

Chat personalizado publicado automaticamente no Hugging Face Spaces pelo GitHub Actions.

- Personalização: edite o `config.yml` (nome, cor, logo, prompt).
- Deploy: cada commit na branch `main` roda os testes e, se passarem, publica.
- Chave da API: fica nas configurações do Space, nunca neste repositório.

Material do Instituto NTA.
